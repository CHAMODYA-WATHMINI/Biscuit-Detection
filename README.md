# Biscuit-Detection

## Project Description

This project detects biscuits in images and classifies them as:

* Intact biscuits
* Broken biscuits

 ## Tools & Libraries

* Python
* OpenCV
* NumPy

## Image processing methods

* Convert image to grayscale
* Apply thresholding
* Detect contours
* Use shape features to classify biscuits

## How to Run

1. Open `image processing assignment.ipynb`
2. Set input and output folder paths
3. Run all cells

## Results

* Green = Intact biscuits
* Red = Broken biscuits

## Example Outputs

Processed images are available in the repository showing:
- Detected biscuits
- Classification as intact or broken
